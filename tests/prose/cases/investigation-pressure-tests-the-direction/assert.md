The prose should have taken this path:

1. the investigation is already registered as in progress, so the entry
   skill resumes rather than gathering bug context — no interview
2. the processing skill finds the investigation file and puts the resume
   choice to the user, who continues
3. symptom gathering is skipped — an earlier session already interviewed
   the user — and the plan step reads the ledger, finds the plan agreed,
   and re-renders the position rather than running recon again
4. the analysis is complete on disk: no code is re-traced and no root
   cause is re-synthesised over what is already written
5. the root cause validation is offered and declined. Nothing is
   dispatched for it
6. the findings are retold from the investigation file and signed off
7. fix approaches are explored and presented through the engine — a
   payload of options written to the phase cache, then the surface
   rendered. The walk composes no comparison of its own
8. **agreeing the direction is what commissions the pressure test.** The
   user answers the fix-direction gate once and the walk dispatches the
   fix-validation agent off that answer. It never asks a second time
   whether to run it
9. the agreed direction is recorded in the investigation file's Fix
   Direction section and committed
10. the agent's report is promoted and its row closed, a verdict payload
    is written to the phase cache, and the engine renders the report
11. the verdict is clean, so nothing is asked of the user — the walk
    carries on to the conclude gate and stops there

Further claims:

- there is no fix-validation offer to answer. A second gate standing
  between agreeing a direction and testing it is what this case exists
  to catch
- the verdict payload carries what the agent found, not merely that it
  passed: the approach it confirms by name, the checks it worked
  through, its own summary sentence, and the path to the full analysis
- the direction named in that payload is the one the user agreed and the
  one written into the file — the verdict and the record cannot name
  different approaches
- the root-cause validation is still an offer. Declining it dispatches
  no agent, and the walk moves on to sign-off
- the investigation is not concluded. The walk stops at the gate that
  asks, leaving the phase in progress
