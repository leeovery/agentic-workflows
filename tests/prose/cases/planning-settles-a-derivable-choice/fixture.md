A feature whose plan is constructed and graphed: two approved phases,
three tasks in local-markdown with dependencies and priorities applied,
the spec baseline recorded — but no review has run and the plan is not
concluded.

The specification decides that card is the only payment method, that a
gateway rejection surfaces as a user-visible checkout error, that a
duplicate checkout start reuses the existing intent, and that duplicate
webhook deliveries are idempotent. It names no idempotency key, and
neither does the discussion nor the plan — the tree holds no gateway
client to measure one against.

The context was cleared mid-phase — this session opens cold at the
entry skill with nothing but the two arguments and what is on disk.
