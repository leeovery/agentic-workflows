Manage is where a piece of work changes shape or standing: a feature made an epic or folded into one, work cancelled, or cancelled work brought back; and where the project's own environment setup and drivers change, and the matrix of my calls opens. Work in progress is listed first, then what is complete, then what was cancelled.

# → A number opens that piece of work, with what can be done to it as it stands.
s → Setup shows the project's environment setup — how to run it, what prepares its environment, what can't run at once and its linters — for you to change; the verify setup shows beside them, changed only by the task that builds it.
d → Drivers shows the task driver and the landing driver in use, and the others that ship, for you to change either.
m → Matrix shows, for each kind of question, how often you changed my lean and what my answer would have cost, and is where your threshold and care entries are set.
b → Back returns to the start menu.

Ask → Ask anything about managing work
