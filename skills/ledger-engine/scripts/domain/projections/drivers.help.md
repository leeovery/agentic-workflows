The drivers are what Ledger works through: the task driver keeps the build's tasks in your tracker, and the landing driver lands each task's change in your repository. Each kind's drivers that ship are listed, the one in use marked; a driver that lands through a host your project's remote isn't on says so, and can't be chosen. A build never changes driver under it, so a driver changes only while no build is in flight.

# → A number makes that driver the one in use.
b → Back returns to manage.

Ask → Ask anything about the drivers
