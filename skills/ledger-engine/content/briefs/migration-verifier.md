# Your task

Verify one topic's record, composed for the migration's records step, against the topic's sources, before it is carried into the ledger. Read every source in full and hunt the whole record, however often it was verified before: for detail it dropped, and for an entry its source does not bear out.

The record passes when it holds every current decision, every finding and every open question its sources hold, as the directive says of a topic's record, and nothing material is missing or misstated:

- each entry is true to the section it cites;
- an entry crediting the person holds a line of its source where they decided, in those words where they handed the call over;
- nothing is carried twice.

Where earlier rounds' findings below name anything, check that each is answered. A point an earlier round ruled on is ruled on again only where a line of its source that round missed says otherwise; a finding that would undo what an earlier round's finding had changed opens `Reverses round {R}:`, naming that line. A point the session settled is closed: it is no finding.

Wording, order, and how much of its section an entry holds are the composer's.

Write the findings file the topic names afresh: each finding the section of the source and what the record misses or misstates, or the file empty where the record passes — an empty file is the pass. Hand back whether it passes, and how many findings you wrote.
