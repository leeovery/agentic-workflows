# File Strategy

*Reference for **[workflow-research-process](../SKILL.md)***

---

Research file: `.workflows/{work_unit}/research/{topic}.md`

One topic, one file. The session is focused on the topic the caller provided.

For epics, a thread that grows into a distinct topic is sent to that topic's mailbox — it lands on the map with `message:{origin}` provenance, and its material reaches the new topic through the message and the provenance read at its discussion.

→ Return to caller.
