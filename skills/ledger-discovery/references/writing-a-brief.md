# Writing a Brief

*Reference for **[approving-the-map.md](approving-the-map.md)**, **[changing-the-map.md](changing-the-map.md)** and **[starting-this-work.md](starting-this-work.md)***

---

A topic's brief is written as it lands on the map, and the discussion that decides the topic opens from it. Draft it in the conversation's cache from everything explored about the topic — from the picture too, where one was read: the person's leans, the paths rejected and why, the open questions, the detail explored, and what a spike showed, each point linking the part of the log it came from. Each point from before that bears on the topic is carried too, marked as from before, with its id and the file it is in; one the person took up in this conversation is their view, linked as any other, its id kept. So is each shared file that bears on the topic, with a line on what it holds and whether it is reference or still to read. Write each link as its path from the state root — a log's with its anchor, `.product/sessions/session-NNN.md#{anchor}` in the product's conversation and `{home}/discovery/session-NNN.md#{anchor}` in an epic's, and the record's files among them — never relative to the draft, which lands unchanged in its topic's folder. Nothing in it is a decision, and it is not the list of what the person will be asked.
