# Writing a Brief

*Reference for **[approving-the-map.md](approving-the-map.md)**, **[changing-the-map.md](changing-the-map.md)** and **[starting-this-work.md](starting-this-work.md)***

---

A topic's brief is written as it lands on the map, and the discussion that decides the topic opens from it. Draft it in the conversation's cache from everything explored about the topic — in the product's conversation, from its picture: the person's leans, the paths rejected and why, the open questions, the detail explored, and what a spike showed, each point linking the part of the log it came from. Each point of an earlier record that bears on the topic is carried too, marked as earlier, with its id and the file it is in; one the person took up in this conversation is their view, linked as any other. Write each link as the log's path from the state root with its anchor — `.product/sessions/session-NNN.md#{anchor}` in the product's conversation, `{home}/discovery/session-NNN.md#{anchor}` in an epic's — never relative to the draft, which lands unchanged in its topic's folder. Nothing in it is a decision, and it is not the list of what the person will be asked.
