What can be done to a piece of work depends on where it stands. A feature can become an epic, or join one, until its spec is written; from then on a decision that has to change is settled in the phase the work is in, so only cancel stays.

p → Pivot makes the feature an epic, its discussion the first topic on the epic's map.
o → Absorb makes the feature a topic of an epic still before its spec, its discussion, experiments and files moving with it, and the feature itself gone.
c → Cancel stops the work where it stands, once you confirm; it can be brought back.
r → Reactivate brings cancelled work back, in progress again where it stood, with each roadmap item its cancel put back that still waits there.
b → Back returns to the list the work was opened from: manage, or the closed units.

Ask → Ask anything about this piece of work and what can be done to it
