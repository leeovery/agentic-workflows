Manage is where a piece of work changes shape or standing: a feature made an epic or folded into one, work cancelled, or cancelled work brought back. Work in progress is listed first, then what is complete, then what was cancelled.

# → A number opens that piece of work, with what can be done to it as it stands.
s → Setup shows the project's environment setup — how to run it, what prepares its environment, what can't run at once and its linters — for you to change; the verify setup shows beside them, changed only by the task that builds it.
b → Back returns to the start menu.

Ask → Ask anything about managing work
