# Living with it

Once the product exists, the everyday rhythm is the same door and the same habit. You press `s`, describe the feature or the bug or the small fix, and the system takes it down the right path. Thoughts that arrive at the wrong moment needn't derail you: say "log that as an idea", or as a bug, or as a quick fix, and it lands in the inbox to be picked up from the start menu whenever you're ready. Nor is work locked to the shape it began with. A feature that outgrows itself becomes an epic, a stray feature can be absorbed into one, topics can be cancelled and brought back, and any finished phase can be reopened, with the system marking whatever was built on it so nothing stale gets trusted by mistake.

Whenever something on screen is unclear, press `h` for help from the start menu, or just ask, right there in the conversation.

```
   when you press done

   ○  the start menu, with everything in flight
   ○  press s, and say what's on your mind
   ○  h/help brings you back here any time
```
